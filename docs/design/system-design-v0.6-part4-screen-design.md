### 各画面操作権限補足

```
P10: LAN構成管理
　└ 参照：全ロール
　└ インポート操作：LAN設計者のみ
　└ 行削除：LAN設計者のみ（参照中データがある場合は警告表示）

P11: サブセット管理
　└ 参照：全ロール
　└ 新規追加・編集・削除：LAN設計者のみ
　└ 削除時参照チェック：警告表示して削除可能
　└ 変更履歴：保持する

P40: ECU Port参照
　└ 参照：全ロール
　└ 更新：ECU設計者（自担当ECUのみ）・LAN設計者（全ECU）
　└ 更新は申請書経由（承認フローを通す）
　└ 今フェーズでは画面からの直接更新操作は未実装

P50: 公開バージョン一覧
　└ 参照：全ロール
　└ 断面確定操作：LAN設計者のみ
```
