### 画面共通ヘッダー：プロジェクト切替（Phase2-1で新設）

```
【配置】画面最上部の共通ヘッダーバー（全画面共通・P00を除く）

┌─────────────────────────────────────┐
│ 🔵 [Gen1プロジェクト ▼]    {ロール名}さん │
├─────────────────────────────────────┤
│ サイドメニュー │ メインコンテンツ         │

【ドロップダウン展開時】
┌───────────────┐
│ 🔵 Gen1プロジェクト  ✓│ ← 現在選択中
│ 🟢 Gen2プロジェクト   │
│ 🟡 Gen3プロジェクト   │
├───────────────┤
│ プロジェクト管理へ →  │ ← P02への導線
└───────────────┘

・プロジェクト名クリックで即座に切替（全ロール操作可）
・切替後、画面全体が選択プロジェクトのデータ・
　テーマカラーに切り替わる
・ヘッダー・サイドバー全体の背景色が選択中プロジェクトの
　テーマカラーで表示される（実装確定：当初案の「左端カラーバー」
　ではなく背景全体を塗る方式を採用。プロジェクト切替のドロップダウン
　等の浮遊パネルはテーマカラーに追従させず常にニュートラルな
　配色のままとする）
・「プロジェクト管理へ」リンクからP02へ遷移

【テーマカラーの適用範囲】
・ヘッダーバー・サイドバーの背景色に反映
　（アクティブなメニュー項目・ホバー状態は白の半透明オーバーレイで
　　表現し、どのテーマカラーでも文字の可読性を保つ）
・全画面共通で作業中プロジェクトが視覚的に判別可能
・固定パレット（P02で選択）は白文字との可読性を優先し、
　やや暗めのトーンで統一する
```

### 各画面操作権限補足

```
P02: プロジェクト管理
　└ 参照（一覧表示）：全ロール
　└ プロジェクト切替：全ロール（P02画面内・共通ヘッダーいずれからも可）
　└ 新規作成・削除・リセット・テーマカラー設定：LAN設計者のみ
　└ 削除・リセットは物理削除（プロジェクト名入力による確認必須）

P10: LAN構成管理
　└ 参照：全ロール
　└ インポート操作：LAN設計者のみ
　└ 行削除：LAN設計者のみ（参照中データがある場合は警告表示）

P11: サブセット管理
　└ 参照：全ロール
　└ 新規追加・編集・削除：LAN設計者のみ
　└ 削除時参照チェック：警告表示して削除可能
　└ 変更履歴：保持する

P40: ECU Port参照
　└ 参照：全ロール
　└ 更新：ECU設計者（自担当ECUのみ）・LAN設計者（全ECU）
　└ 更新は申請書経由（承認フローを通す）
　└ 今フェーズでは画面からの直接更新操作は未実装

P50: 公開バージョン一覧
　└ 参照：全ロール
　└ 断面確定操作：LAN設計者のみ
```

#### P02: プロジェクト管理画面（Phase2-1で新設）
```
【背景】Issue #1（データベースの初期化機能不足）対応。
開発・検証中にデータをリセットする手段、サンプルデータ投入手段、
複数プロジェクトの切替・削除手段がなかったことに対応する
恒久機能として新設。

【画面構成】
┌────────────────────────────────────┐
│ プロジェクト一覧                      │
│ ●🔵 Gen1プロジェクト ┤01/01│[切替][リセット][削除]│
│ ●🟢 Gen2プロジェクト ┤02/01│[切替][リセット][削除]│
│                                     │
│ [新規プロジェクト作成]（LAN設計者のみ）│
│ 　└ プロジェクト名・テーマカラー選択  │
│ 　└ 「サンプルデータで開始」選択肢     │
│ 　　（samples/配下のデータを初期投入） │
├────────────────────────────────────┤
│ 【データリセット】（LAN設計者のみ）    │
│ 対象プロジェクト：[Gen1プロジェクト▼] │
│ [リセット実行]ボタン                 │
│ ・確認ダイアログ：                   │
│ 　「削除するプロジェクト名を入力してください」│
│ 　[入力欄] [実行][キャンセル]        │
│ ・入力値が一致した場合のみ実行可能    │
└────────────────────────────────────┘

【操作フロー】
プロジェクト切替（全ロール）
　└ 一覧の[切替]ボタン、または共通ヘッダーのドロップダウンから実行
　└ 切替後は全画面が選択プロジェクトのデータ・テーマカラーで表示

新規プロジェクト作成（LAN設計者のみ）
　└ プロジェクト名・テーマカラーを指定
　└ 「空のプロジェクトで開始」または
　　 「サンプルデータで開始」を選択
　└ 作成後、自動的にそのプロジェクトに切替

リセット（LAN設計者のみ）
　└ 対象プロジェクトを選択
　└ プロジェクト名を入力して確認 → 一致時のみ実行可能
　└ 実行：紐づく全コレクションのレコードを物理削除
　　（ecus/buses/frames/signals/applications/approvals/
　　 gwRoutes/snapshots/changelogs/versionHistories/
　　 subsetHistories/variants/accessControls）
　└ projectsレコード自体は保持（名称・テーマカラーは残る）

削除（LAN設計者のみ）
　└ リセットと同様の確認方式
　└ 実行：リセットの全処理に加えprojectsレコード自体も削除
```
